## 🌟 Overview

**HireMind AI** is an autonomous full-stack platform designed to revolutionize interview preparation. By combining real-time voice-driven mock interviews, deep context extraction from candidate resumes, comprehensive evaluation metrics powered by **Google Gemini**, and a gamified learning hub, HireMind turns stressful job prep into an engaging, structured mastery experience.

---

## ✨ Key Features

### 🎙️ 1. Real-Time Autonomous Voice Interviews
- **Context-Aware Interviewer:** Dynamically personalizes technical and behavioral interview questions based on the candidate's uploaded resume and chosen domain.
- **Voice & Speech Interaction:** Supports speech synthesis and speech-to-text input for a hyper-realistic mock interview room.
- **Adaptive Follow-Ups:** Listens, reacts, and drills deeper into technical details based on candidate responses.

### 📊 2. Deep Performance Scoring & Radar Analytics
- **Multidimensional Scoring:** Instant breakdown across **Technical Knowledge**, **Communication**, **Confidence**, and **Problem-Solving**.
- **Actionable AI Feedback:** Detailed candidate strengths, red flags, and pinpoint improvement tips generated by Google Gemini.

### 📄 3. ATS Resume Analyzer
- **PDF Extraction:** Parses resumes with PyPDF, evaluating readability and keyword density.
- **ATS Compatibility Scoring:** Pinpoints formatting flaws, missing skills, and provides structured suggestions to beat recruiter tracking systems.

### 🏆 4. Gamified Progression & Global Leaderboard
- **XP & Tier Ranking:** Earn XP from completed interviews, code challenges, and daily practice to level up from *Recruit* to *Legend*.
- **Daily Streaks & Multipliers:** Incentivizes continuous daily learning with streak tracking and badge unlocks.
- **Global Leaderboard:** Compete with peers globally on total XP and rank metrics.

### 🎓 5. Interactive Learning Hub & Code Proctoring
- **In-Browser IDE:** Integrated Monaco Editor with syntax highlighting, live code execution, and test cases.
- **AI Tutoring & Hints:** On-demand AI hints without spoiling full solutions.
- **Anti-Cheat & Proctoring:** Tab-switch tracking, snapshot verification, and mentor review queues.
- **Verified Credentials:** Generates cryptographically verifiable PDF certificates with unique QR codes upon course completion.

### 🛡️ 6. Role-Based Portals (Candidate, Mentor, Admin)
- **Candidate Hub:** Personal analytics, interview history, skill radar, and actionable learning roadmap.
- **Mentor Portal:** Grade code submissions, evaluate exam sessions, and leave tailored feedback.
- **Admin Center:** System-wide metrics, candidate tracking, course CRUD, and platform settings.

## 🏗️ Architecture & Tech Stack

`
HireMind AI Architecture
├── Frontend (Next.js 16 + React 19 + TypeScript + Tailwind CSS v4)
│   ├── App Router (Candidate / Mentor / Admin / Learning / Verification)
│   ├── Monaco Editor & Framer Motion UI
│   └── jsPDF & html2canvas for Certificate Generation
│
├── Backend (FastAPI + Python 3.13 + Uvicorn)
│   ├── Services: LLM, Speech, Email, Proctoring & Playwright
│   ├── Dual Database Layer: Local SQLite <-> Production PostgreSQL
│   └── Background Task Scheduler (APScheduler)
│
└── Infrastructure & Cloud
    ├── Frontend Hosting: Vercel
    ├── Backend Hosting: Render
    └── Database: Supabase Serverless PostgreSQL
`

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | Next.js 16 (Turbopack), React 19, TypeScript, Tailwind CSS v4, Framer Motion, Lucide Icons, Monaco Editor |
| **Backend** | FastAPI, Python 3.13, Uvicorn, Pydantic, APScheduler, PyPDF, ReportLab |
| **AI / LLM** | Google Gemini 2.0 / 1.5 Flash, Groq API (fallback / accelerated inference) |
| **Database** | Dual SQLite (hiremind.db) for zero-config local dev & PostgreSQL (Supabase) for production |
| **Deployment** | Vercel (Frontend), Render (Backend), Supabase (PostgreSQL) |

## 🚀 Getting Started

### Prerequisites
- **Node.js:** 18.18+ or 20+
- **Python:** 3.10+ (Python 3.13 recommended)
- **Git**

---

### 1. Clone the Repository
`ash
git clone https://github.com/KrSanib1544/Hiremind-AI.git
cd Hiremind-AI
`

---

### 2. Backend Setup
`ash
cd backend

# Create & activate virtual environment (optional but recommended)
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Create environment configuration
cp .env.example .env

# Run FastAPI backend
python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
`
Backend will start at: http://localhost:8000 (API Docs at http://localhost:8000/docs).

---

### 3. Frontend Setup
`ash
# In a separate terminal:
cd frontend

# Install dependencies
npm install

# Create environment configuration
cp .env.local.example .env.local

# Run Next.js development server
npm run dev
`
Frontend will start at: http://localhost:3000.
